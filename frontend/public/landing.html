Defense-in-depth
for every execution

Text-to-SQL is unsafe without deterministic validation. We do not rely on prompt warnings alone. Every candidate query traverses structural AST validation before it is ever sent to the PostgreSQL engine.

AST Parser sqlglot walks full syntax tree; forbids INSERT, UPDATE, DELETE, DROP, ALTER, TRUNCATE Deterministic
Multi-Stmt Rejects stacked queries separated by semicolons to block SQL injection attacks Blocked
Schema Check Resolves table & column nodes against introspected schema to block hallucinated objects Verified
Timeout Enforces SET statement_timeout = '30000' on database connection + asyncio.wait_for 30,000ms
Row Bounding Injects LIMIT 1000 automatically if query contains no user-specified row bound 1,000 Rows
Read-Only Read-only connection sessions ensure zero mutations occur on the persistent store Enforced
